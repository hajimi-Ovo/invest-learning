### 资产配置与组合管理（8 月主线）

8 月课程的前后逻辑：**宏观定位 → 资产定价 → 行为纠偏 → 配置与纪律**。

- **宏观之锚**：经济周期、通胀、货币政策、菲利普斯曲线 → 汇率、国际收支、财政政策、滞胀（Part 1–2）
- **资产定价**：利率期限结构与收益率曲线、久期、股票 DCF 与相对估值、股权风险溢价（ERP）与股债性价比、分散化与有效前沿（Part 3）
- **配置与纪律**：因子投资（三因子/多因子）、资产配置框架（资本加权→风险平价）、风险管理与仓位控制、再平衡与执行纪律、投资体系复盘（Part 5 / Part 7）
- **另类与全球**：另类投资总览、大宗商品与通胀对冲（Contango/Backwardation、展期成本）、黄金、REITs、地理分散与汇率风险（Part 8）

- **三大报表与杜邦分析**：资产负债表/利润表/现金流量表的勾稽关系
- **财务排雷与盈利质量**：应收、存货、现金流与利润的背离如何识别"漂亮报表"

- **行业与公司研究框架**：从宏观到个股的落地路径、能力圈

- **可转债**：债底 + 内嵌看涨期权、转股价值与溢价率、下修/强赎/回售、双低策略
- **信用债与信用利差**：预期损失 + 风险溢价、评级体系、违约与回收

### 基金与指数投资

- **基金底层结构**：集合投资制度、持有人/管理人/托管人"铁三角"、基金财产独立与托管、净值与申赎机制（September/Part 2，9.5 起）
- **基金类型地图**：投资对象（货币/债券/混合/股票/QDII）× 管理方式（主动/被动）× 交易渠道（场外/场内 ETF/LOF）
- **指数体系**：上证指数、沪深300、中证500/1000、标普500、纳斯达克、道琼斯
- **基金分类**：ETF、ETF联接、FOF、QDII、货币基金、指数增强、主动管理型
- **核心指标**：夏普比率、卡玛比率、信息比率、Alpha/Beta、最大回撤
- **估值方法**：市盈率（PE）、市净率（PB）、历史分位
- **投资行为**：定投微笑曲线、追涨杀跌、频繁交易的复利损耗

> 📄 核心笔记：`September/Part 2.md`、`June/Fund Financial（6.4-6.11）.md`、`20260630_周二.md`

### 期权与衍生品

从零理解期权定价逻辑与策略选择：

- **期权本质**：未来选择权的保险费，买方风险有限、卖方风险无限
- **定价三要素**：内在价值、时间价值、隐含波动率
- **核心关联**：利率（时间成本）↔ 机会成本（决策比较）↔ 时间价值
- **希腊值**：Delta、Gamma、Theta、Vega
- **杠杆效应**：虚值期权的超高杠杆与归零风险
- **期货**：做空机制、合约要素、保证金制度

> 📄 核心笔记：`20260702_周四` → `20260703_周五` → `20260704_周六` → `20260706_周一` → `20260707_周二` → `20260710_周五`

### 宏观经济与货币体系

- **宏观框架**：经济周期与美林时钟、通货膨胀（需求拉动/成本推动/货币超发）、货币政策工具、菲利普斯曲线、滞胀困局
- **开放宏观**：汇率定价、国际收支账本、财政政策与总需求（8 月 Part 1–2）
- **国民收入核算**：GDP 定义与性质、支出法/收入法、名义 vs 实际、同比/环比（7.29–7.31）
- **货币派生**：存款创造机制、货币乘数、法定准备金
- **信贷配给**：信息不对称、逆向选择、银行的"安全优先"逻辑
- **财政赤字货币化**：MMT 理论 vs 传统经济学，通胀/通缩风险
- **利率本质**：资金的价格，跨期消费的效用补偿，机会成本的锚
- **非农数据**：就业 → 收入 → 消费 → 企业利润 → 经济循环

> 📄 核心笔记：`August/Part 1.md` → `Part 2.md` → `20260729–31` → `20260717–18` → `20260709_周四` → `June/Fund Financial`

### 金融底层逻辑与风险

- **奈特不确定性**：风险（概率已知）vs 不确定性（概率未知）
- **风险分配**：保险（锁定生存下限）、衍生品（对冲市场波动）
- **金融本质**：对"稀缺安全"的跨时空分配，将不确定性转化为可定价资产
- **金融市场与个人**：资金的跨期调配、价格信号指导职业与投资
- **金融创新与监管**：金融创新的双刃剑效应、影子银行的期限错配风险、第三方支付监管逻辑

> 📄 核心笔记：`20260721_周二` → `20260722_周三` → `20260723_周四` → `20260725_周六`

### 经济学基础理论

- **机会成本**：五维视角（决策、要素定价、会计-经济、比较优势、动态跨期）
- **成本效益原则**：所有经济学概念的源头
- **边际成本**：低果先摘原则
- **经济租金与寻租**：超额利润的来源与争夺
- **一价定律与套利**：市场自我修复的底层机制
- **存量与流量**：时点值（快照）vs 区间值（录像），收入与财富的核心区分
- **休克疗法**：价格自由化、财政紧缩、私有化三管齐下——俄罗斯 1992 年案例与 IMF 救助

## 🔗 双链笔记与知识图谱

本仓库使用 **Obsidian** 管理，笔记之间通过高精度双链链接：

- **块引用** `#^xxxxx` — 精确到段落级别的引用，悬停即可预览
- **标题锚点** `#标题名` — 精确到小节
- **深层关联** — 知识点之间追求内在逻辑关联，而非浅层主题归类

两个典型例子：

- `September/Part 2`（9.5）在解释"基金财产为何安全"时，通过块引用 `#^a9b8c7` 直跳 `September/Part 1`（9.3）的 **SPV 破产隔离**——把"资产脱离主体风险"这一思想在两类产品间打通。
- `August/Part 8`（8.30）在讲商品展期成本时，以 `#^y1y2y3` 回链 8.8 滞胀、以 `#^e5f6g7` 回链 8.12 分散化——跨 Part 精确跳转，无需全文搜索。

## 🤖 AI 协作规范

仓库配备 `CLAUDE.md` 文件，定义 AI 助手在整理笔记时的标准化工作流：

1. **内容审校** — 事实正确性 + 写作风格审查（去应试化、去人称化、客观真实、严谨通俗）
2. **格式检查** — Markdown 层级、LaTeX 规范、Callout 元素
3. **添加 Frontmatter** — YAML 属性块（date、tags、type、status）
4. **添加深度双链** — 精确到块引用/标题锚点，杜绝纯笔记链接
5. **结构约定** — 8 月起按"4 天一篇 Part"组织，篇内日期为 H1；每日期末附去重后的关联笔记
6. **弯引号排查** — 链接锚点引号必须与目标标题一致（常见错误之一）
7. **推送至 GitHub** — 整理完成后提交推送
