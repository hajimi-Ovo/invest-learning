## 🧠 知识领域速览

- **宏观经济与货币**：经济周期、通胀、货币政策、汇率与国际收支、财政政策、货币派生、GDP 核算
- **资产定价与组合**：收益率曲线与久期、股票 DCF、股权风险溢价、投资组合理论、因子投资
- **行为金融**：前景理论、认知偏差、羊群与泡沫、有效市场与被动投资
- **财务与公司研究**：三大报表与杜邦、财务排雷、估值进阶、行业研究、资本结构与并购
- **信用与固收**：可转债、信用债与信用利差、资产证券化、信用风险谱系
- **基金与指数**：基金底层结构、分类与风格、费用解剖、评价与挑选、指数体系
- **个人财务**：应急储备金、保险、生命周期配置、退休提取与投资政策书
- **衍生品**：期权定价三要素与希腊值、期货与做空、无套利/二叉树/Black-Scholes
- **商业模式与一级市场**：单位经济、规模与网络效应、产业链、私募股权与风险投资
- **系统化/量化**：规则化框架、回测陷阱、交易成本与容量、因子评估与合成
- **技术分析**：K 线形态、成交量与量价、分时图、均线系统
- **投资实务与阅读**：打新机制、税收与交易成本；《纳瓦尔宝典》《牛奶可乐经济学》
