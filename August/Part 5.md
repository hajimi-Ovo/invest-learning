# 2026.8.17

## 因子投资：把市场收益拆成可辨识的来源

### 前置：从"异象"到"因子"

8.16 [[August/Part 4#^y8z9a1|市场异象]] 显示：小盘股、高账面市值比股票长期存在统计上的超额收益。这些超额是运气，还是存在系统性的来源？

**因子（Factor）** 由此而来：因子是一组**具有共同特征、收益联动**的资产组合。用少数几个因子，可以解释绝大部分资产收益的差异。 ^f1f2g3

### 一、单因子起点：市场因子与 Beta

最早、也最重要的因子是**市场因子**——整个市场组合（如沪深 300）的涨跌。单个资产与市场的关系，可用一个数字概括：

$$
E(R_i) = R_f + \beta_i \times [E(R_m) - R_f]
$$

其中 $R_f$ 为无风险利率，$E(R_m)$ 为市场预期收益，$\beta_i$ 为资产的**贝塔**——对市场波动的敏感度（[[June/Fund Financial（6.4-6.11）#^b7a6b5|基金收益拆解]] 中的 Beta 即此意）。

- Beta = 1：与市场同步；Beta = 1.5：涨跌放大 1.5 倍；Beta = 0：与市场无关（如货币基金）；Beta < 0：与市场反向（避险属性）；
- 市场因子溢价 $E(R_m) - R_f$，正是 8.11 [[August/Part 3#^c3d4e5|股权风险溢价（ERP）]] 的定价对象；
- 单因子模型的局限：一个"市场"无法解释所有差异——相同市场环境下不同股票表现迥异，需要更多因子。 ^g2h3i4

### 二、Fama-French 三因子：规模与价值

1992 年，法玛与弗伦奇在单因子基础上加入两个新因子，构成**三因子模型**：

| 因子 | 含义 | 指向 |
| :--- | :--- | :--- |
| **市场因子 MKT** | 市场组合超越无风险利率的部分 | 承担系统性风险 |
| **规模因子 SMB** | 小市值股 − 大市值股 | 小盘股长期平均跑赢大盘股 |
| **价值因子 HML** | 高账面市值比 − 低账面市值比 | 价值股长期平均跑赢成长股 |

三因子回归：

$$
E(R_i) - R_f = \alpha + b_1 \text{MKT} + b_2 \text{SMB} + b_3 \text{HML}
$$

- 多因子把"超额"从神秘的 Alpha 转为可解释的**因子暴露**——8.16 [[August/Part 4#^w6x7y8|EMH]] 眼中的异象，在三因子框架下变成了系统性风险的另一维度；
- 规模与价值溢价长期存在，但**不是免费午餐**：小盘股与价值股在特定时期（如流动性紧缩）会剧烈回撤，溢价是对风险的补偿。 ^h3i4j5

### 三、因子的行为金融解释：理性补偿还是集体偏差

三因子模型能描述收益差异，但**为什么**存在溢价，学界分两派：

- **理性解释（风险补偿）**：小盘股流动性差、破产风险高，价值股经营杠杆大、对宏观更敏感——溢价是承担这些风险的报酬；
- **行为解释（偏差定价）**：投资者过度外推成长股的过去表现（8.14 [[August/Part 4#^o7p8q9|代表性偏差]]），把价值股过度打压、把成长股过度追捧，偏差修正时便产生溢价；
- 后续扩展：卡哈特加入**动量因子**（追涨的延续，连接 8.15 [[August/Part 4#^t3u4v5|羊群效应]]），法玛-弗伦奇再扩展为**五因子**（加入盈利、投资）——因子数量随证据积累不断演进。 ^i4j5k6

### 四、Smart Beta 与因子投资实践

因子投资把"主动判断"转化为"规则化暴露"——介于 8.16 [[August/Part 4#^a2b3c4|被动指数]] 与主动选股之间：

- **策略指数（Smart Beta）**：按规则持有特定因子暴露的股票池，如红利、低波动、价值、质量指数——7.12 [[July/上半月/20260712_周日|红利指数与股息率]] 中的中证红利低波动指数即"红利 + 低波动"双因子叠加；
- **因子择时之难**：因子长期有效、短期可能长期失效（价值因子在成长风格主导时可能落后多年），因子暴露需能承受巨大回撤；
- **分散化持有因子**：与分散化股票同理，跨因子配置（价值、动量、质量、低波同时持有）比押注单一因子更稳健——8.12 [[August/Part 3#^e5f6g7|组合理论]] 的分散化逻辑在因子层面的延伸。 ^j5k6l7

### 五、启示

- **超额收益先问"来自哪个因子"**：在归因之前，任何超额都可能是运气——把收益拆解为 Beta（市场）、因子暴露与残差，是理性评估业绩的第一步；
- **因子是"风格"而非"圣杯"**：因子溢价是对风险的补偿或偏差的修正，不保证任何时刻有效；
- **与被动投资的统一**：因子投资是"聪明的被动"——承认无法战胜市场，但通过规则化暴露于已被验证的收益来源，向市场索取合理的风险溢价。

# 2026.8.18

## 资产配置框架：从资本加权到风险平价

### 前置：组合理论之后，"配多少"仍是开放问题

8.12 [[August/Part 3#^e5f6g7|组合理论]] 证明了分散化能降低风险、画出了有效前沿，但没有回答实践中最关键的问题：**各资产到底该配多少权重**。8.17 讨论了"有哪些收益来源"，今天讨论"怎么把这些来源组合成一份可执行的配置"。

- 配置框架的演进主线：**资本加权（60/40）→ 限制主动（核心-卫星）→ 风险加权（风险平价）→ 状态全覆盖（全天候）**；
- 核心转变：从"按资本多少配"走向"按风险贡献配"。 ^k6l7m8

### 一、60/40：经典股债组合的直觉与盲点

**60/40 组合**（60% 股票 + 40% 债券）是资产配置的经典基准：

- **直觉**：股票提供长期增长，债券提供稳定缓冲（8.9 [[August/Part 3#^z1z2z3|债券]] 的稳定属性 + 8.10 [[August/Part 3#^z0a1b2|股票]] 的增长属性）；
- **盲点**：按**资本**配比，但**风险**并不均衡——典型假设下股票波动率约为债券的 3 倍，60/40 组合的总风险约 90% 来自股票。名义上是"股 60 债 40"，实际风险暴露几乎全押在股票上；
- **边界**：当股债相关性趋同（危机中同跌），债券的缓冲作用打折（8.15 [[August/Part 4#^v5w6x7|泡沫识别]] 中资产同涨同跌的警示）。 ^l7m8n9

### 二、核心-卫星：把主动限制在小范围

**核心-卫星策略（Core-Satellite）**：用低成本的被动指数做"核心"打底，用少量资金做"卫星"博取超额：

- **核心（通常 70–90%）**：宽基指数或 [[August/Part 4#^a2b3c4|被动指数]] 组合，获取市场平均回报，成本极低；
- **卫星（通常 10–30%）**：主题、行业、[[August/Part 5#^j5k6l7|Smart Beta 因子]] 或主动基金，博取超越核心的收益；
- **逻辑**：承认多数主动策略长期难以跑赢指数（8.16 [[August/Part 4#^y8z9a1|指数难以被战胜]]），但仍保留一部分"有纪律的主动"——既控制整体风险，又保留进攻弹性。 ^m8n9o1

### 三、风险平价：让每类资产贡献相同的风险

**风险平价（Risk Parity）**：不再按资本配权重，而是让每类资产对组合总风险的**贡献**大致相等。

- 在忽略相关性的简化下，单类资产对组合的风险贡献近似为 $w_i \times \sigma_i$（权重 × 波动率），风险平价令：
$$
w_1 \sigma_1 = w_2 \sigma_2
$$
即高波动资产配低权重、低波动资产配高权重（完整形式见 8.12 [[August/Part 3#^f6g7h8|组合方差公式]]）；
- 由此债券权重远高于 60/40，组合需要**加杠杆**才能达到合意的总风险——杠杆是风险平价的关键变量，也是主要风险源；
- **优势**：组合不被单一资产主导，收益来源更均衡；**代价**：利率上行期债券端承压，杠杆在危机中放大波动，且过度使用杠杆正是泡沫与踩踏的燃料（20260717 [[July/下半月/20260717_周五#^e6f7g8|过度信用扩张]]）。 ^n9o1p2

### 四、全天候组合：不预测，覆盖所有经济状态

**全天候组合（All Weather）**：由桥水基金达利欧提出，不预测宏观方向，而是让组合在**四种经济状态**下都有资产表现：

| 经济状态 | 相对占优的资产 |
| :--- | :--- |
| 增长 + 通胀 | 股票、大宗商品 |
| 增长 + 通缩 | 股票、债券 |
| 衰退 + 通胀（滞胀） | 大宗商品、通胀挂钩债 |
| 衰退 + 通缩 | 债券 |

- **与美林时钟的区别**：美林时钟 [[August/Part 1#四、经济周期对投资的含义|预测周期并轮动]]，全天候**不预测、全覆盖**——四个象限各配一部分，永远有资产处在"正确的位置"；
- **本质是风险平价在宏观层面的应用**：对四种状态的**风险贡献**做均衡，而非对四类资产的**资本**做均衡；
- **局限**：状态划分是简化，现实中滞胀（8.8 [[August/Part 2#^y1y2y3|滞胀]]）等极端组合仍可能击穿假设，股债相关性突变时分散化效果打折。 ^o1p2q3

### 五、启示

- **配置先于选择**：对多数投资者，"股债各占多少"比"买哪只股票"的影响大得多；
- **从资本思维转向风险思维**：看组合先问"风险来自哪里"，而不是"钱放在哪里"；
- **没有完美框架，只有适合的框架**：60/40 简单、核心-卫星灵活、风险平价均衡、全天候全覆盖——关键是匹配自身的风险承受力与认知边界，并坚持执行与再平衡。

## 风险管理与仓位控制：把"风险"变成可管理的数字

### 前置：风险管理的四步闭环

8.12 [[August/Part 3#^e5f6g7|组合理论]] 用波动率度量风险，8.13 [[August/Part 4#^h2i3j4|损失厌恶]] 说明亏损的痛感是盈利的 2 倍以上——风险在数学上可度量，在心理上却常被低估。风险管理就是把"感觉上的风险"转成"可管理的数字"：

- **识别**：组合里有哪些风险源（市场、行业、利率、杠杆）；
- **度量**：每类风险有多大（回撤、波动、在险价值）；
- **定价**：承担风险要求多少补偿（8.11 [[August/Part 3#^c3d4e5|股权风险溢价]]）；
- **控制**：用仓位、止损、对冲把风险压到承受范围内。 ^p2q3r4

### 一、最大回撤与波动率：描述"跌多少、多颠簸"

- **最大回撤（Max Drawdown）**：从任意峰值到随后谷底的**最大跌幅**，衡量"最坏情况下账面会亏多少"——比波动率更贴近实际感受，因为体验的是"从高点亏下来"的落差；
- **卡玛比率** = 年化超额收益 ÷ 最大回撤（[[June/Fund Financial（6.4-6.11）#^t5u6v7|卡玛比率]]）：数值越大，说明以更小的最深跌幅换取了同等收益——与夏普比率（[[June/Fund Financial（6.4-6.11）#^q8r9s0|夏普比率]]）分别衡量"日常平稳度"与"底线防守"；
- **波动率（标准差）**：收益围绕均值的离散程度，是 8.12 组合方差公式的平方根——描述"日常颠簸"，与最大回撤互补。 ^q3r4s5

### 二、VaR（在险价值）：描述"可能亏多少"

**VaR（Value at Risk，在险价值）**：在给定置信水平与时间窗口下，组合可能的最大损失。例：某组合**1 天 95% VaR = 2 万元**，含义是"95% 的概率，单日亏损不超过 2 万元；仍有 5% 的概率亏损超过 2 万元"。

- **计算直觉**：若日收益率近似正态分布，95% VaR ≈ 均值 − 1.65 × 标准差；
- **用途**：给"风险预算"设上限——单笔仓位、整个组合都能用 VaR 约束；
- **局限（致命伤）**：VaR 只描述"常规区间"，**不捕捉尾部**——那 5% 的区间恰恰包含崩盘。它回答"通常最多亏多少"，却对"极端时亏多少"几乎无语（2008 年金融危机中，多家机构依据 VaR 显示组合"安全"，随即遭遇远超模型的亏损）。 ^r4s5t6

### 三、凯利公式：最优仓位来自胜率与赔率

**凯利公式（Kelly Criterion）**：给定胜率与赔率，计算让长期资金增长最快的**下注比例**：

$$
f^* = \frac{bp - q}{b}
$$

其中 $f^*$ 为最优仓位比例，$b$ 为赔率（赢时每 1 元本金赚多少），$p$ 为胜率，$q = 1-p$ 为败率。

- **例**：$p = 0.6$、$b = 1$ → $f^* = (1\times0.6 - 0.4)/1 = 0.2$，即每次投入资金的 20%；
- **三个洞见**：① 只有 $bp > q$（期望为正）才值得下注；② 优势越大仓位越高，但**永远不满仓**；③ 过度自信（8.14 [[August/Part 4#^q9r0s1|过度自信与确认偏差]]）会让实际下注超过凯利上限，长期反而拉低收益；
- **现实折中**：参数估计存在误差，实践中常用**半凯利**（$f^*/2$），牺牲部分增速换取更低回撤。 ^s5t6u7

### 四、仓位与止损的实践纪律

- **单一标的上限**：单只股票、单个行业的仓位设上限，防止个股风险主导组合（8.12 分散化逻辑的落地）；
- **止损单**：预设退出价，把"单次错误"的代价锁死——正是对 8.13 [[August/Part 4#^i3j4k5|处置效应]]"死扛亏损"的机械对冲；
- **压力测试**：模拟极端情景（利率急升、股市暴跌），看组合是否扛得住——比 VaR 更能暴露尾部；
- **对冲工具**：期权等衍生品可作"保险单"，以有限成本转移极端风险（见关联笔记的期权入门）。 ^t6u7v8

### 五、启示

- **先想"最多亏多少"，再想"能赚多少"**：入场前设定可承受的亏损边界，是纪律的第一条；
- **用风险预算代替收益目标**：把风险管理嵌入决策流程，用 VaR、仓位上限约束每一步；
- **承认尾部不可测**：任何数字模型都测不出"未知的未知"，保留安全边际（现金、低杠杆）是对不确定性的最终防御。
