# 2026.8.21

## 财务报表基础：三大报表与杜邦分析

### 前置：财务报表是公司的"体检报告"

上市公司的定期报告，本质是回答三个问题：

| 报表 | 回答的问题 | 性质 |
| :--- | :--- | :--- |
| **资产负债表** | 公司此刻有多少家底？ | 存量（某时点） |
| **利润表** | 这段期间赚了多少？ | 流量（一段区间） |
| **现金流量表** | 真金白银到手多少？ | 流量（收付实现） |

- "存量 vs 流量"正是 7.28 [[July/下半月/20260728_周二#三、 核心关联：流量如何影响存量|存量与流量]] 在公司层面的具体化；
- 三张表是 8.10 [[August/Part 3#^z0a1b2|估值]] 的输入层：DCF 需要自由现金流，PE 需要盈利——不懂报表，估值就是空中楼阁。 ^b5c6d7

### 一、资产负债表：公司的"家底"（存量）

**恒等式：资产 = 负债 + 所有者权益**

- **资产**：公司拥有或控制的资源（货币资金、应收账款、存货、固定资产、无形资产）；
- **负债**：欠外部人的钱（银行借款、应付账款、应付债券）；
- **所有者权益**：真正归属股东的（股本 + 留存收益），也叫"净资产"；
- **用途**：看财务结构——负债占比（杠杆率）与偿债能力；8.17 [[August/Part 5#^h3i4j5|价值因子]] 的账面市值比，其分子"账面价值"正是净资产。 ^c6d7e8

### 二、利润表：公司的"成绩单"（流量）

利润表记录一段时期的经营成果，核心链条可浓缩为：

$$
\text{净利润} = \text{营业收入} - \text{营业成本} - \text{费用} - \text{所得税} + \text{营业外净额}
$$

- 关键比率：**毛利率** = 毛利 ÷ 营收（产品或服务的赚钱能力）；**净利率** = 净利润 ÷ 营收（剔除费用与税后的最终留存）；
- **重要陷阱**：利润表按**权责发生制**记账——确认收入不必收到现金，费用也不一定当期支付。账面利润可观，现金却可能并未到账（应收账款高企）。 ^d7e8f9

### 三、现金流量表：公司的"真金白银"

现金流量表按现金实际收付记账，分三部分：

| 部分 | 内容 | 关注点 |
| :--- | :--- | :--- |
| **经营现金流** | 主营业务收到的净现金 | 是否与净利润匹配（盈利质量） |
| **投资现金流** | 买卖资产、对外投资的现金 | 资本开支大小 |
| **筹资现金流** | 借款、发债、增发、分红的现金 | 是否依赖外部输血 |

- **盈利质量**：经营现金流持续明显低于净利润，说明利润可能停留在"账面"（应收账款、存货积压）；
- **自由现金流（FCF）** = 经营现金流 − 资本开支——这是 8.10 [[August/Part 3#^z0a1b2|DCF]] 折现的标的，也是估值的真正输入。 ^e8f9g1

### 四、杜邦分析：把 ROE 拆开看

**ROE（净资产收益率）** = 净利润 ÷ 净资产，是衡量股东回报的核心指标。杜邦分析把它拆成三个驱动因子：

$$
\text{ROE} = \frac{\text{净利润}}{\text{营收}} \times \frac{\text{营收}}{\text{总资产}} \times \frac{\text{总资产}}{\text{净资产}} = \text{净利率} \times \text{资产周转率} \times \text{权益乘数}
$$

- **净利率**：盈利能力（卖得贵 / 成本控制好）；
- **资产周转率**：运营效率（同样的资产做多大的生意）；
- **权益乘数**：杠杆水平（总资产是净资产的几倍）。

**洞察**：同样的 ROE，来源可以完全不同——高净利率（品牌与定价权，如高端白酒）、高周转（薄利多销，如零售）、高杠杆（放大回报，如银行）。**只看 ROE 数字不够，要看它由哪个因子驱动**，高杠杆推高的 ROE 在去杠杆时会快速塌陷。 ^f9g1h2

### 五、对投资的启示

- **估值的地基**：盈利（8.11 [[August/Part 3#^c3d4e5|ERP]] 的输入）与自由现金流（DCF 的输入）都来自报表，财务分析是"自下而上"估值的必经之路；
- **看报表要结合周期**：繁荣期盈利与现金流同旺、衰退期同衰（8.1 [[August/Part 1#^d1d2d3|经济周期]]），单期数字需放在周期位置里解读；
- **排雷优先于掘金**：利润与现金流背离、应收激增、存货异常，往往是财务质量恶化的预警信号。
