# 2026.8.21

## 财务报表基础：三大报表与杜邦分析

### 前置：财务报表是公司的"体检报告"

上市公司的定期报告，本质是回答三个问题：

| 报表 | 回答的问题 | 性质 |
| :--- | :--- | :--- |
| **资产负债表** | 公司此刻有多少家底？ | 存量（某时点） |
| **利润表** | 这段期间赚了多少？ | 流量（一段区间） |
| **现金流量表** | 真金白银到手多少？ | 流量（收付实现） |

- "存量 vs 流量"正是 7.28 [[July/下半月/20260728_周二#三、 核心关联：流量如何影响存量|存量与流量]] 在公司层面的具体化；
- 三张表是 8.10 [[August/Part 3#^z0a1b2|估值]] 的输入层：DCF 需要自由现金流，PE 需要盈利——不懂报表，估值就是空中楼阁。 ^b5c6d7

### 一、资产负债表：公司的"家底"（存量）

**恒等式：资产 = 负债 + 所有者权益**

- **资产**：公司拥有或控制的资源（货币资金、应收账款、存货、固定资产、无形资产）；
- **负债**：欠外部人的钱（银行借款、应付账款、应付债券）；
- **所有者权益**：真正归属股东的（股本 + 留存收益），也叫"净资产"；
- **用途**：看财务结构——负债占比（杠杆率）与偿债能力；8.17 [[August/Part 5#^h3i4j5|价值因子]] 的账面市值比，其分子"账面价值"正是净资产。 ^c6d7e8

### 二、利润表：公司的"成绩单"（流量）

利润表记录一段时期的经营成果，核心链条可浓缩为：

$$
\text{净利润} = \text{营业收入} - \text{营业成本} - \text{费用} - \text{所得税} + \text{营业外净额}
$$

- 关键比率：**毛利率** = 毛利 ÷ 营收（产品或服务的赚钱能力）；**净利率** = 净利润 ÷ 营收（剔除费用与税后的最终留存）；
- **重要陷阱**：利润表按**权责发生制**记账——确认收入不必收到现金，费用也不一定当期支付。账面利润可观，现金却可能并未到账（应收账款高企）。 ^d7e8f9

### 三、现金流量表：公司的"真金白银"

现金流量表按现金实际收付记账，分三部分：

| 部分 | 内容 | 关注点 |
| :--- | :--- | :--- |
| **经营现金流** | 主营业务收到的净现金 | 是否与净利润匹配（盈利质量） |
| **投资现金流** | 买卖资产、对外投资的现金 | 资本开支大小 |
| **筹资现金流** | 借款、发债、增发、分红的现金 | 是否依赖外部输血 |

- **盈利质量**：经营现金流持续明显低于净利润，说明利润可能停留在"账面"（应收账款、存货积压）；
- **自由现金流（FCF）** = 经营现金流 − 资本开支——这是 8.10 [[August/Part 3#^z0a1b2|DCF]] 折现的标的，也是估值的真正输入。 ^e8f9g1

### 四、杜邦分析：把 ROE 拆开看

**ROE（净资产收益率）** = 净利润 ÷ 净资产，是衡量股东回报的核心指标。杜邦分析把它拆成三个驱动因子：

$$
\text{ROE} = \frac{\text{净利润}}{\text{营收}} \times \frac{\text{营收}}{\text{总资产}} \times \frac{\text{总资产}}{\text{净资产}} = \text{净利率} \times \text{资产周转率} \times \text{权益乘数}
$$

- **净利率**：盈利能力（卖得贵 / 成本控制好）；
- **资产周转率**：运营效率（同样的资产做多大的生意）；
- **权益乘数**：杠杆水平（总资产是净资产的几倍）。

**洞察**：同样的 ROE，来源可以完全不同——高净利率（品牌与定价权，如高端白酒）、高周转（薄利多销，如零售）、高杠杆（放大回报，如银行）。**只看 ROE 数字不够，要看它由哪个因子驱动**，高杠杆推高的 ROE 在去杠杆时会快速塌陷。 ^f9g1h2

### 五、对投资的启示

- **估值的地基**：盈利（8.11 [[August/Part 3#^c3d4e5|ERP]] 的输入）与自由现金流（DCF 的输入）都来自报表，财务分析是"自下而上"估值的必经之路；
- **看报表要结合周期**：繁荣期盈利与现金流同旺、衰退期同衰（8.1 [[August/Part 1#^d1d2d3|经济周期]]），单期数字需放在周期位置里解读；
- **排雷优先于掘金**：利润与现金流背离、应收激增、存货异常，往往是财务质量恶化的预警信号。

# 2026.8.22

## 财务排雷与盈利质量：如何识破"漂亮的报表"

### 前置：报表是"制作"出来的，需要带着怀疑去读

8.21 [[August/Part 6#^b5c6d7|三大报表]] 提供了看懂公司的语言，但会计是一门可以被操纵的语言——报表上的数字，是管理层在会计准则框架内"制作"出来的。**盈利质量**指的就是利润的"含金量"：账面上的盈利，有多少能转化为真金白银、又能持续多久。

- 排雷的意义：被粉饰的盈利会误导 8.10 [[August/Part 3#^z0a1b2|估值]] 与 8.11 的 ERP 判断——在错误的盈利上估值，越精确越危险；
- 本篇不预设"所有公司都造假"，而是建立一套**交叉验证**的读表习惯。 ^a6b7c8

### 一、利润与现金流的背离：最基础的排雷信号

- 8.21 指出利润表按 [[August/Part 6#^d7e8f9|权责发生制]] 记账，而 [[August/Part 6#^e8f9g1|现金流量表]] 按收付实现记账——两表天然可以互相验证；
- **危险信号**：经营现金流长期、显著低于净利润，说明利润可能停留在"账面"（客户欠款未付、存货未售），而非实实在在的现金；
- **应收账款激增**：营收增长但回款恶化——可能靠放宽信用（赊销）"制造"收入，未来坏账风险随之累积；
- 排雷口诀：**利润是观点，现金是事实**。 ^b7c8d9

### 二、资产负债表上的异常信号

资产负债表科目之间的勾稽关系，能暴露隐藏的问题（[[August/Part 6#^c6d7e8|资产负债表]] 是存量的镜子）：

- **应收账款增速远超营收增速**：收入质量存疑，可能靠赊销冲量；
- **存货异常堆积**：产品滞销或过时，未来面临跌价与计提减值；
- **其他应收款、预付账款异常膨胀**：可能被大股东或关联方占用资金；
- **在建工程长期挂账、迟迟不转固**：费用可能被资本化，利润被"推迟"到未来。 ^c8d9e1

### 三、利润表的花样：收入与费用的操纵

利润是最容易被"化妆"的数字：

- **收入确认前移**：提前确认本属未来的收入，把利润做在当前；
- **费用资本化**：把本该当期扣减的费用（研发、利息）计入资产，从而虚增当期利润——8.10 [[August/Part 3#^z0a1b2|DCF]] 与 PE 中的"盈利 E"就此被污染；
- **非经常性损益**：靠出售资产、政府补贴等一次性项目撑起净利润，剔除后主业盈利平平；
- **商誉减值**：高溢价并购形成巨额商誉（账面资产），收购标的业绩不达标时集中计提减值——利润表"爆雷"的常见来源。 ^d9e1f2

### 四、识别框架：把排雷嵌入分析流程

- **ROE 质量**：8.21 的 [[August/Part 6#^f9g1h2|杜邦分析]] 显示，高杠杆推高的 ROE 在去杠杆时脆弱——警惕"高 ROE + 高权益乘数"的组合；
- **异常点优先**：毛利率异于同行、审计意见非标准、频繁变更会计政策或审计机构、关联交易占比过高；
- **账面质量影响因子投资**：价值因子（8.17 [[August/Part 5#^h3i4j5|HML]]）依赖账面市值比，若账面价值本身虚高，因子的"便宜"可能是陷阱；
- **排雷是风险前置**：财务暴雷常带来断崖式下跌，是 8.19 [[August/Part 5#^p2q3r4|风险管理]] 中最大回撤的常见来源。 ^e1f2g3

### 五、对投资的启示

- **排雷优先于掘金**：先排除"看不懂、不可信"的标的，再谈估值与收益；
- **交叉验证三张表**：利润、现金流、资产负债相互印证，任何单表都不能轻信；
- **结合周期与商业逻辑**：行业景气下行期（8.1 [[August/Part 1#^d1d2d3|经济周期]]），财务恶化信号更需警惕——排雷是"自下而上"估值（8.20 决策清单）的必要前置。

# 2026.8.23

## 估值方法进阶：从 PE 到 EV/EBITDA 与 PEG

### 前置：8.10 只是工具箱的入门

8.10 [[August/Part 3#^z0a1b2|DCF]] 与 [[August/Part 3#^z3c4d5|PE]] 建立了估值的基本框架，但不同行业、不同盈利状态的公司，需要不同的"尺子"。本篇补三把常用尺——**EV/EBITDA**（重资产/高负债）、**PEG**（成长股）、**PS 与 FCF 收益率**（未盈利与现金牛），并讨论如何为一家公司选择合身的估值方法。 ^a7b8c9

### 一、EV/EBITDA：绕过资本结构的"尺子"

- **EV（企业价值）** = 市值 + 净负债（总负债 − 现金）——买下整家公司需要花的钱，直接来自 [[August/Part 6#^c6d7e8|资产负债表]]；
- **EBITDA** = 息税前利润 + 折旧摊销——来自 [[August/Part 6#^d7e8f9|利润表]]，剔除了资本结构与折旧政策的影响；
- **EV/EBITDA 相对 PE 的优势**：排除负债水平与折旧计提的差异，适合高负债、重资产行业（钢铁、公用事业、基建）；
- **局限**：EBITDA 忽略了资本开支与营运资金占用——账面 EBITDA 很高但现金流很差的"纸面繁荣"会被高估（呼应 8.22 [[August/Part 6#^d9e1f2|盈利质量]] 的排雷意识）。 ^b8c9d1

### 二、PEG：把"增长"装进估值

$$
\text{PEG} = \frac{\text{PE}}{\text{盈利增长率（%）}}
$$

- **直觉**：高增长公司配高 PE 是合理的——PE 20、增长率 20% 时 PEG = 1；PEG < 1 通常视为相对便宜；
- **意义**：把"静态的贵贱"升级为"相对增长的贵贱"，适合盈利高速成长的科技与消费股；
- **致命前提**：增长率是**估计值**——过度自信（8.14 [[August/Part 4#^q9r0s1|过度自信与确认偏差]]）会让人把"乐观假设"当"客观事实"；一旦增长率不可持续，PEG 立即失真。 ^c9d1e2

### 三、PS 与 FCF 收益率：亏损与现金牛怎么办

- **PS（市销率）** = 市值 ÷ 营业收入：适用于尚未盈利的早期成长公司（如部分科技股）——营收比利润更难操纵、也更稳定；
- **FCF 收益率** = 自由现金流 ÷ 市值：把股票的"现金回报"与债券收益率直接比价——这是 8.11 [[August/Part 3#^c3d4e5|股权风险溢价]] 的现金流版本（8.21 [[August/Part 6#^e8f9g1|自由现金流]] 是分子）；
- 这两个指标天然呼应 8.22 的提醒：**利润可被化妆，营收与现金流相对更难造假**。 ^d1e2f3

### 四、选择框架：不同行业用不同的尺

| 公司类型 | 特征 | 相对合身的估值 |
| :--- | :--- | :--- |
| **周期股**（钢铁/有色/航运） | 盈利随经济周期剧烈波动，低点 PE 反而高 | PB、EV/EBITDA |
| **金融股**（银行/保险） | 资产驱动、负债经营 | PB |
| **成长股**（科技/医药） | 盈利高速增长 | PEG、PS |
| **现金牛**（消费/公用事业） | 现金流稳定 | FCF 收益率、DCF |

- 周期股在盈利低点 PE 反而高——因为盈利被压到极低，此时用 PB 或 EV/EBITDA 更可靠（盈利随 8.1 [[August/Part 1#^d1d2d3|经济周期]] 波动）；
- 金融股是"资产驱动"的生意，估值核心在 [[August/Part 6#^c6d7e8|资产负债表]]，PB 比 PE 更贴合；
- **分部估值（SOTP）**：多元化集团按业务分部分别估值再加总，避免"整体打折"；
- 相对估值的两大参照——可比公司（横向）与自身历史分位（纵向），8.10 [[August/Part 3#^z4d5e6|成长股 vs 价值股]] 已涉及；关键是不脱离行业属性与盈利质量空谈指标。 ^e2f3g4

### 五、启示

- **估值是区间，不是点位**：多种方法交叉验证，结果互相印证才可信；
- **先确认"镜子有没有装歪"**：盈利质量（8.22）是任何估值方法的前提——用被粉饰的数字套公式，只会得到精确的错误；
- **方法论服从商业逻辑**：选择估值方法的依据是行业与公司的生意模式，而非哪个数字"好看"——这是 8.20 决策清单中"自下而上"环节的深化。

# 2026.8.24

## 行业与公司研究框架：从宏观到个股的落地路径

### 前置：打通自上而下与自下而上

8.20 的决策清单中，"资产贵不贵"（8.23 [[August/Part 6#^a7b8c9|估值]]）是自下而上的终点，但在此之前先要回答两个更根本的问题：**这行业是不是好行业？这家公司是不是好公司？** 本篇给出一套可操作的落地框架——自上而下看 8.1 [[August/Part 1#^d1d2d3|经济周期]] 定方向，行业层看五力与生命周期定格局，公司层看护城河与财务定优劣，最终汇入 8.20 决策清单。 ^f3g4h5

### 一、行业层：波特五力定行业盈利格局

波特五力模型（Michael Porter）判断一个行业长期能有多赚钱，取决于五种力量的对抗：

| 力量 | 含义 | 对行业利润的影响 |
| :--- | :--- | :--- |
| **现有竞争强度** | 行业内厂商的对抗激烈程度 | 竞争越烈，价格战越凶，利润越薄 |
| **潜在进入者威胁** | 新玩家进入的难度（进入壁垒） | 壁垒越高，在位者利润越有保障 |
| **替代品威胁** | 其他产品/服务抢走需求的能力 | 替代越容易，定价权越弱 |
| **供应商议价能力** | 上游原料/要素的谈判地位 | 供应商越强，行业成本越被动 |
| **购买者议价能力** | 下游客户砍价的能力 | 客户越集中，行业利润越被挤压 |

- **五力皆弱 → 行业格局好**：竞争温和、壁垒高、上下游分散，行业整体利润率高且可持续；
- **应用**：判断"行业空间大"之外更要看"格局好不好"——空间大但竞争惨烈的行业，个体未必受益。 ^g4h5i6

### 二、行业生命周期：不同阶段，不同逻辑

行业通常经历四个阶段：**导入期 → 成长期 → 成熟期 → 衰退期**。阶段不同，估值方法与风险特征都不同（下表"合身方法"呼应 8.23 的 [[August/Part 6#^e2f3g4|选择框架]]）：

| 阶段 | 特征 | 合身估值 | 主要风险 |
| :--- | :--- | :--- | :--- |
| **导入期** | 市场小、技术路线未定 | 市梦率/情景分析 | 需求证伪、技术淘汰 |
| **成长期** | 增速快、格局未定 | PEG、PS | 增速不及预期 |
| **成熟期** | 增速放缓、格局稳定 | FCF 收益率、DCF | 增长停滞、估值下移 |
| **衰退期** | 需求萎缩、竞争加剧 | 谨慎，警惕"便宜陷阱" | 需求长期下滑 |

- **关键**：增长率与生命周期位置强相关——把成熟期公司的历史增速外推，是典型的线性外推错误；
- 生命周期阶段还决定风险特征：成长期的高波动与成熟期的低波动，直接影响 8.19 风险管理中的仓位与回撤预期。 ^h5i6j7

### 三、公司层：护城河与财务验证

**护城河（Economic Moat）**：能长期抵御竞争、维持超额盈利的结构性优势。常见来源：

1. **无形资产**——品牌（白酒/奢侈品）、专利、特许经营权；
2. **转换成本**——客户迁移成本高（企业软件、银行账户）；
3. **网络效应**——用户越多价值越大（平台型生意）；
4. **成本优势**——规模、资源、工艺带来的低成本；
5. **有效规模**——市场容量有限，容不下第二个玩家（区域公用事业）。

- **财务是结果，护城河是原因**：高 ROE（8.21 [[August/Part 6#^f9g1h2|杜邦分析]]）与稳定的盈利质量（8.22 [[August/Part 6#^d9e1f2|盈利质量]]）是护城河在账面上的投影——先问"为什么能持续赚钱"，再用报表交叉验证"确实在赚钱"；
- **护城河会变**：技术颠覆、监管变化、需求迁移都会填平护城河，需要动态评估而非一劳永逸。 ^i6j7k8

### 四、常见误区

- **把"好行业"当"好公司"**：行业空间大不等于公司能分到蛋糕——格局（五力）比空间更重要；热门行业里鱼龙混杂，易触发代表性偏差（8.14 [[August/Part 4#^o7p8q9|代表性偏差]] 的"以貌取股"）；
- **把"历史增长"当"未来增长"**：线性外推忽略了生命周期阶段与竞争格局的变化；
- **把"便宜"当"价值"**：衰退期或周期高点的低估值可能是"价值陷阱"（呼应 8.23 选择框架中周期股的 PE 陷阱）。 ^j7k8l9

### 五、落地：三层漏斗汇入决策清单

- **宏观定方向**（8.1 [[August/Part 1#^d1d2d3|经济周期]]）→ **行业定格局**（五力/生命周期）→ **公司定优劣**（护城河/财务/估值）；
- 每一层过滤一层风险，最终落到 8.20 [[August/Part 5#^w9x1y2|决策清单]] 的买入执行与 8.19 的仓位纪律；
- **与有限有效和解**：多数时候承认市场、保持在场（8.16 [[August/Part 4#^a2b3c4|被动投资]]），分析的价值在于识别极端偏离的少数时刻——框架不是每天预测的工具，而是极端处敢于下注的依据。 ^k8l9m1
