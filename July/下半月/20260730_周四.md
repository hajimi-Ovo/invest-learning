# GDP 三大核算方法

## 前置核心定义

**国内生产总值（GDP）**：一定时期内，一个国家/地区境内，所有常住单位生产的**最终产品和服务的市场总价值**。有关 GDP 的定义与流量属性可参考 [[July/下半月/20260729_周三#一、 GDP 的定义与性质|GDP 的定义与流量属性]]。

两大核心原则（所有计算都围绕这两点）：

1. **不重复计算**：只算**新创造的价值**，外购的、别人已经生产过的中间产品必须剔除。关于避免重复计算的详细论述，参见 [[July/下半月/20260729_周三#二、 避免重复计算：最终产品 vs 中间产品|最终产品与中间产品的区分]]。
2. **只算最终产品**：进入消费、投资、出口的产品，用于再生产的原材料（中间品）不计入。

GDP 三大核算方式：**生产法（增加值法）、支出法、收入法**，理论上三者计算结果完全相等。^7a1b2c

## 一、生产法（增加值法）——最严谨的核算方式

核心逻辑：**GDP = 全社会所有企业的增加值之和** ^d3e4f

> 生产法（增值法）是避免重复计算最严谨的方法，详见 [[July/下半月/20260729_周三#三、 增值法（生产法）|增值法详解]]。

### 1. 核心公式

**单个企业增加值 = 企业总产出价值 − 中间投入成本**

- 总产出：企业当期生产、销售的产品/服务总收入；
- 中间投入：企业向外采购的原材料、辅料、水电、外包服务等（**别人生产的产品，本期用于再生产**）；
- ✅ 不扣除：工资、利润、租金、税收、折旧（属于本企业新创造的价值）。

### 2. 经典产业链案例（小麦→面粉→面包）

完整链条拆分，逐环节算增加值：

1. **农民（第一环节）**：产出小麦价值100，无外购中间投入 → 增加值 = 100 − 0 = **100**
2. **面粉厂（第二环节）**：产出面粉价值200，外购小麦成本100（中间投入） → 增加值 = 200 − 100 = **100**
3. **面包厂（第三环节）**：产出面包价值300，外购面粉成本200（中间投入） → 增加值 = 300 − 200 = **100**

**全社会GDP（生产法）= 100 + 100 + 100 = 300**

### 3. 单企业实操案例

面包店卖面包总收入100元，采购面粉、鸡蛋、电费等中间投入60元。

面包店单家企业增加值 = 100 − 60 = **40元**

> [!tip] 关键总结
> 单看单个企业，必须扣中间成本；看全链条总和，等于最终产品售价。

### 4. 极简结论

- 单独统计**某一家企业**：必须扣上游成本，只算自身新增价值；
- 统计**整条产业链GDP**：所有企业增加值相加，结果=最终产品售价，无重复计算。

## 二、支出法——最直观的核算方式

核心逻辑：**谁花钱买了这些最终产品，花的钱总和就是GDP**

### 1. 核心公式（四部门公式）

**GDP = 消费(C) + 投资(I) + 政府购买(G) + 净出口(NX)** ^g5h6i

净出口 NX = 出口(X) − 进口(M)

### 2. 分项详细解读

- **消费C**：居民日常消费（衣食住行、教育、医疗、娱乐等），是GDP最大组成部分。银行信贷扩张通过货币派生机制能够支持居民消费，详见 [[July/下半月/20260717_周五#^4b8c9d|货币派生与居民消费]]。
- **投资I**：企业固定资产投资、厂房设备建设、存货增加（注意：**居民买房算投资，不算消费**）；
- **政府购买G**：政府采购公共产品、发放公务员工资、基建建设（**转移支付不算**，如低保、养老金、救济金）；
- **净出口NX**：本国卖给外国的产品，减去外国卖给本国的产品。

### 3. 产业链案例验证

最终面包售价300元，被居民购买消费：

GDP = 消费300 + 投资0 + 政府购买0 + 净出口0 = 300，和生产法结果一致。

## 三、收入法（分配法）——从收益角度核算

核心逻辑：**生产创造的价值，最终会分配给各个生产要素，要素收入总和=GDP**

### 1. 核心公式

**GDP = 工资 + 利息 + 租金 + 企业利润 + 间接税 + 折旧** ^j7k8l

### 2. 分项解读

- 劳动收入：职工工资、奖金、社保；
- 资本收入：存款利息、股权收益；
- 土地收入：厂房、店铺租金；
- 企业收入：营业利润；
- 政府收入：间接税（增值税、消费税）；
- 折旧：固定资产损耗补偿（属于当期产出价值）。

### 3. 核心特点

所有企业新创造的增加值，最终都会以各类收入的形式分配出去，因此收入法结果与生产法、支出法完全相等。

## 四、三大方法核心对比

| 核算方法 | 核算视角 | 核心口诀 | 适用场景 |
|:---|:---|:---|:---|
| 生产法（增加值法） | 生产端：创造了多少价值 | 总产出减中间投入 | 理论研究、分行业统计 |
| 支出法 | 需求端：谁花钱买了产品 | 消投政净四部分相加 | 宏观经济需求分析 |
| 收入法 | 分配端：价值分给了谁 | 劳资租利税折收入总和 | 收入结构分析 |

## 五、高频易错点

1. **中间品vs最终品**：面粉卖给面包厂是中间品（不计入GDP），面粉卖给居民家用是最终品（计入GDP）；
2. **重复计算误区**：不能直接加总各环节总产值（100+200+300=600），必须用增加值或最终产品价格；
3. **不计入GDP的项目**：二手商品交易、股票基金买卖、政府转移支付、自产自用无市场交易的产品；
4. **单企业vs全链条**：单企业增加值必扣成本，全链条增加值总和=最终产品售价，二者不矛盾。
