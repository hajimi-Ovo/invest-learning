# 2026.9.29

## 市场的参与者：资金属性如何塑造行为

### 前置：价格是所有参与者共同写下的结果

- 过去三个月里，各类参与者陆续出现过：公募基金（9.5–9.8）、私募股权与风险投资（Part 7）、对冲基金（7.9）、做市商（8.26）、保险与养老金（9.10、9.11），以及个人投资者；
- 但它们始终是**分别出现**的。本篇把它们放到同一张图上，回答一个问题：为什么不同参与者在同一个市场里，会做出差别如此之大的选择；
- 主要答案不是"聪明程度"的差异，而是**约束条件**的差异——资金的性质、期限与考核方式，决定了谁能承受什么、又会被迫做什么。 ^4l5m6n

### 一、三类约束：期限、负债与考核

- 判断一类资金的行为，可以先问三个问题：
  - **期限**：这笔钱能锁定多久？（养老金可长达数十年，公募基金面对每日申赎，对冲基金常有季度赎回窗口）；
  - **负债**：它背后是否存在刚性支出承诺？（保险与养老金有未来的给付义务，因此更看重长期匹配而非短期涨幅）；
  - **考核**：它按什么被评价？（绝对收益还是相对排名，季度还是一到三年）；
- 三条约束互相牵制：**期限越短、负债越刚性、考核越频繁，行为就越趋同、越偏短期**——这不是道德问题，而是约束下的必然结果；
- 一个直接推论：当考核周期与资产回报周期错配时，理性的选择往往是**跟随基准、避免独立**——因为偏离基准的短期代价由管理人承担，而长期正确带来的回报可能落在考核期之后。这类由委托结构产生的行为偏移，与 9.5 讨论的基金三方结构同源（[[September/Part 2#^r1s2t3|持有人·管理人·托管人]]）。 ^5m6n7o

### 二、按资金属性排列：从最长期到最短期

- 把主要参与者按"期限—考核"排列，会看到一条清晰的光谱：
  - **主权基金与养老金**：期限最长、负债最长期，考核以年计，最能承受短期波动与低流动性资产，因而成为长期资产的主要出资方（Part 7 中的 LP 结构，[[September/Part 7#^9p1q2r|GP 与 LP]]）；
  - **保险资金**：负债刚性明确，核心诉求是**期限匹配与稳定现金流**，配置上偏向长久期债券与现金流稳定的资产（保险作为风险转移机制的定位见 9.10 [[September/Part 3#^5z6a7b|保险的本质]]）；
  - **公募基金**：面对每日申赎、按相对排名考核，规模即是收入来源，因此对短期业绩与规模波动高度敏感——这与风格漂移、同格扎堆的现象直接相关（9.6 [[September/Part 2#^1d2e3f|风格漂移与同格扎堆]]）；
  - **对冲基金**：追求绝对收益，收费结构（管理费加业绩分成）激励高波动策略；但业绩压力同样短期化，且面临赎回约束；
  - **做市商**：不以方向判断为主要盈利来源，赚取的是买卖价差与流动性提供的报酬（8.26 [[August/Part 7#^t8u9v1|做市商与买卖价差]]）；
  - **个人投资者**：若资金性质允许，期限本可以最长，且没有外部考核，自由度最大——但正因为缺少约束，也最容易被情绪驱动（8.13–8.15 的行为偏差即属此类）；
- 一个反直觉但重要的观察：**理论上约束最轻的个人投资者，行为上却常常最短期化**——不受考核约束的同时，也失去了迫使自己长期持有的外部纪律。 ^6n7o8p

### 三、同一根约束链上的"委托—代理"

- 大量机构资金的管理链条是多层的：**最终受益人 → 受托机构 → 资产管理人 → 具体交易**，每一层都有自己的考核与激励；
- 链条每增加一层，**期限偏好就更容易被压缩**：最终受益人关心的是数十年后的养老给付，但中间每一层都按年度或季度被评价，于是整体行为会向最短的那一环靠拢；
- 因此"机构更理性、个人更情绪化"的通行印象并不完整：机构同样会做出趋同、追逐短期业绩的行为，只是成因不同——**个人的偏差来自心理，机构的偏差来自委托结构**；
- 这也提示了一种判断方法：观察一笔资金的**实际约束**，而不是它的名义类型，往往更能预测它会怎么做（公司层面的同类问题，见 9.15 对代理成本的讨论，[[September/Part 4#^9e1f2g|股利无关论与代理成本]]）。 ^7o8p9q

### 四、参与者结构解释了哪些市场现象

- 参与者的构成，可以解释若干反复出现的现象：
  - **抱团**：考核趋同与基准约束，使不同机构在同一时间内倾向于持有相似的资产；
  - **结构性低估**：无法进入大型机构可投池的资产（市值过小、流动性不足），长期可能缺乏买方关注；
  - **波动的自我放大**：被动资金与风险预算规则的机械买卖，会在下跌中形成非线性抛压（8.15 的信息瀑布与羊群，[[August/Part 4#^t3u4v5|信息瀑布]]）；
  - **短期业绩的相互强化**：排名压力使管理人倾向于在已有共识上加注，而非逆势独立判断；
- 需要保持克制的是：这些机制解释的是**群体倾向**，不是某个具体价格的成因。把"机构会抱团"直接当作交易依据，等于把一个统计规律当成了确定性结论。 ^8p9q1r

### 五、对投资者的含义

- 这层认知的实际价值，在于**明确自己的相对优势在何处**：若资金可以长期锁定、不必对委托人作季度解释、能够承受短期浮亏，那么恰好具备长期资金的核心条件——这三件事看似平常，却是多数机构不被允许拥有的（配置逻辑见 9.11 [[September/Part 3#^2f3g4h|风险承受能力随生命阶段变化]]，落地为一页纪律见 9.12 [[September/Part 3#^1n2o3p|投资政策书]]）；
- 反过来要警惕**错位模仿**：照搬机构的重仓与持仓披露，等于接受了机构的约束，却没有机构的信息与交易能力；
- 一条可操作的次序是：先确认自己资金的期限与负债（哪些钱不能用、多久不需要动用），再据此选择能承受的策略——顺序颠倒，往往在需要用钱时被迫卖出最好的资产；
- 一句收束：**理解参与者，是为了理解价格的成因，也是为了确认自己站在哪个位置上**——市场上的每一个价格，都是不同约束下一群人共同写下的结果。 ^9q1r2s
